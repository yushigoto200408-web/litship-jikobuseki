# LitShip 自己分析アプリ

就職活動やキャリア選択に向けて、自分の経験・価値観・強みを整理するための対話型Webアプリです。

## 概要

開始画面から案内に沿って質問に回答し、最後に自己分析の結果を振り返る構成です。

## ファイル構成

```text
litship-jikobuseki/
└── index.html  # アプリ本体（HTML / CSS / JavaScript）
```

## 使い方

1. `index.html` をダウンロードするか、リポジトリをクローンします。
2. ブラウザで `index.html` を開きます。
3. 最初の案内に従って入力し、対話を進めます。
4. 最後のまとめ画面で回答を振り返ります。

単一HTMLファイル構成のため、通常の表示確認にビルドコマンドは必要ありません。

## 更新・テスト

- 画面表示、質問文、動作は主に `index.html` で管理します。
- 変更後は「開始 → 対話 → まとめ」の一連の流れを操作して確認してください。
- PCとスマートフォンで、入力欄・戻る操作・長文表示などを確認してください。
- ユーザーの回答を扱うため、データの保存・外部送信の有無はコードを確認したうえで案内してください。

## プライバシー

自己分析には個人的な経験や希望進路が含まれます。実名や個人の回答をIssue・コミット・公開資料に貼り付けないでください。公開運用時はデータの取扱いと公開範囲を確認してください。
